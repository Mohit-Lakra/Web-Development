Text Basics in HTML

Headings

HTML provides six levels of headings, from <h1> to <h6>, with <h1> being the most important and <h6> being the least important.

Paragraphs

A paragraph in HTML is defined using the <p> tag. It is used to group sentences and sections of text together.

Break line and horizontal line

The <br> tag is used to insert a line break, while the <hr> tag is used to insert a horizontal line.

List Types

Unordered List

An unordered list is a list of items in which the order does not matter. It is defined using the <ul> tag, and each item in the list is defined using the <li> tag.

Example of Unordered List

  • Item 1
  • Item 2
  • Item 3

Ordered List

An ordered list is a list of items in which the order does matter. It is defined using the <ol> tag, and each item in the list is defined using the <li> tag.

Example of Ordered List

  1. First Item
  2. Second Item
  3. Third Item

Links and Images

Links

A link in HTML is defined using the <a> tag, which stands for "anchor". The href attribute is used to specify the URL of the page the link goes to.

Example of a Link

Visit Example.com

Images

An image in HTML is defined using the <img> tag. The src attribute is used to specify the path to the image, and the alt attribute is used to provide alternative text for the image.

Example of an Image

Semantics

Semantic HTML refers to the use of HTML tags that convey the meaning of the content they contain. This helps search engines and assistive technologies understand the structure and content of a webpage.

Semantic Tags

  • <header>: Represents the header of a document or a section.
  • <nav>: Represents a section of a page that links to other pages or to parts within the page.
  • <main>: Represents the main content of a document.
  • <article>: Represents a self-contained composition in a document, such as a blog post or news article.
  • <section>: Represents a generic section of a document, typically with a heading.
  • <footer>: Represents the footer of a document or a section.

Tables in HTML

A table in HTML is defined using the <table> tag. The <tr> tag defines a table row, the <th> tag defines a table header, and the <td> tag defines a table cell.

Example of a Table

Forms in HTML

A form in HTML is defined using the <form> tag. It is used to collect user input and submit it to a server for processing. The action attribute specifies the URL of the server-side script that will handle the form submission, and the method attribute specifies the HTTP method to use when submitting the form (usually "GET" or "POST").
